# Workflow Summary

This file documents the key implementation steps completed in this repository and how the system works now.

## 1) LLM Extraction Migration

- Replaced local/Ollama extraction path with OpenAI-based extraction.
- Added OpenAI client wiring under `app/llm/openai_client.py`.
- Kept a strict schema contract in `app/llm/llm_schema.py` and validation in `app/llm/llm_extractor.py`.
- Enforced JSON-only extraction shape:
  - `{"accidents": [...]}`
- Added response/failure logging under `data/` for audit/debug.

## 2) Guardrails and Data Quality

- Added filtering for historical/aggregate reports (non-event summaries should not create accident rows).
- Added casualty sanity limits to reduce unrealistic totals from LLM mistakes.
- District handling is constrained to backend-supported districts.
- Coordinates are always assigned from backend geo mapping (`app/geo.py`), never generated by the LLM.

## 3) Canonical Date Rule

- Implemented rule: `accidents.accident_date` must come from article `published_date`.
- For multi-accident articles, all extracted rows use the same article published date.
- LLM-provided dates are ignored for DB write.

## 4) Published Date Capture Improvements

- Updated `app/scraper.py` to parse published date directly from article HTML.
- Added robust parsing for Daily Star formats (including malformed time strings like `18:03 PM`).
- Added fallback metadata selectors for alternate templates.

## 5) Backfill and Sync

- Added logic to repair missing `articles.published_date` for existing URLs during scrape.
- Added explicit backfill API:
  - `POST /api/backfill-published-dates?limit=5000`
- Backfill also syncs `accidents.accident_date` to the repaired article date.

## Current Runtime Flow

1. Scraper fetches article links from Daily Star listing pages.
2. For each new article, scraper captures title/content/published date.
3. Article is inserted into `articles`.
4. LLM extractor parses accidents in strict JSON.
5. Guardrails + normalization run.
6. Accident rows are inserted with `accident_date = articles.published_date`.
7. Dashboard APIs read from SQLite and power UI cards/charts/maps.
